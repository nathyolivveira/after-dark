# 🌙 After Dark

Um projeto web inspirado na atmosfera da cena **post-punk underground**, criado como projeto de estudo e portfólio.

O **After Dark** tem como proposta explorar bandas, estética e referências da cena alternativa através de uma experiência visual inspirada no universo do post-punk.

## 🚧 Status do projeto

**Em desenvolvimento.**

Este projeto está sendo construído aos poucos enquanto estudo e aprimoro meus conhecimentos em desenvolvimento front-end.

## 💻 Tecnologias

* HTML5
* CSS3
* JavaScript

## 🎯 Objetivos

* Praticar desenvolvimento front-end;
* Aprender e aplicar JavaScript;
* Trabalhar com estruturação e estilização de páginas;
* Desenvolver uma interface visual e interativa;
* Criar um projeto para compor meu portfólio.

## 🎶 Referências

O projeto possui inspiração na estética e atmosfera de bandas da cena post-punk, como **The Cure** e **The Smiths**.
